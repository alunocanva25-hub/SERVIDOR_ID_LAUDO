ID LAUDO V1.0.0.26 - RENDER + SUPABASE AUTH
================================================

CORRECAO CRITICA V26
- Em PostgreSQL/Render, o login agora e obrigatorio e falha fechado.
- Uma variavel antiga ID_LAUDO_AUTH_ENABLED=false nao consegue mais liberar o app online.
- Ao abrir/recarregar o APK, a tela de login permanece ate uma autenticacao valida.
- Sessao antiga da V25 e descartada para forcar o primeiro login correto.
- Cache visual antigo da WebView/Service Worker e eliminado para impedir alternancia entre tela antiga e login.

NOVIDADES
- Tela de login por e-mail/senha.
- Supabase Auth integrado ao Render/FastAPI.
- Administrador principal vinculado ao e-mail configurado.
- Senha inicial do administrador configurada SOMENTE no Render.
- Troca obrigatoria da senha inicial no primeiro acesso.
- "Esqueceu sua senha?" com e-mail de recuperacao.
- ADMIN pode criar, editar, suspender, reativar, enviar reset e excluir usuarios.
- OPERADOR nao ve os cards administrativos de usuarios/campos.

VARIAVEIS DO RENDER
Mantenha:
DATABASE_URL = sua connection string PostgreSQL/Supabase
ID_LAUDO_CATALOG_BACKEND = postgres

Adicione:
ID_LAUDO_AUTH_ENABLED = true
SUPABASE_PUBLISHABLE_KEY = chave Publishable do projeto Supabase
SUPABASE_SECRET_KEY = chave Secret do projeto Supabase
ID_LAUDO_BOOTSTRAP_ADMIN_EMAIL = dayvisant4@gmail.com
ID_LAUDO_BOOTSTRAP_ADMIN_PASSWORD = admin123
ID_LAUDO_PUBLIC_URL = https://id-laudo-api.onrender.com

IMPORTANTE
- SUPABASE_SECRET_KEY nunca deve ir para o APK ou JavaScript. Ela fica apenas no Render.
- admin123 e apenas a senha temporaria de PRIMEIRO ACESSO. O app exige troca apos entrar.
- Depois que o usuario ADMIN for criado, a variavel de senha de bootstrap pode ser removida do Render.
